# 时间管理计划

一个本地优先、农场与漫画界面结合的时间管理网站，包含：

- 课程时刻表与单双周安排
- 校园路线地图与放大视图
- 日常事务目标
- 突发事项管理
- 每日目标打卡
- 三日天气与日期转场
- 局域网多设备同步
- 单文件离线版本

## 直接使用

打开 `index.html`，或下载 `suslov-offline.html` 后直接在浏览器中使用。

## iPad 主屏幕图标

在 Safari 中打开网站，点击“分享”→“添加到主屏幕”，图标会自动使用
`assets/apple-touch-icon.png`。高清封面位于 `assets/icon-1024.png`。

## 局域网同步

1. 在电脑上双击 `start-server.cmd`。
2. 手机、平板和电脑连接同一个 Wi‑Fi。
3. 使用电脑的局域网 IP 加端口 `4173` 访问。

共享数据保存在电脑的 `../work/planner-state.json`，不会提交到 Git 仓库。

## 云端同步

点击页面右上角的同步状态，选择“云同步”，输入至少 12 个字符的同步码。
其他设备输入同一个同步码即可共享数据。同步码不会写入代码仓库。

云同步使用 Supabase，数据库结构见 `supabase-schema.sql`。
